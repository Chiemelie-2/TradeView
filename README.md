# 9minies-power-

TradeVerge.live - Institutional & Private Wealth Investment Platform

A comprehensive investment platform featuring:
- Multi-currency banking & crypto payment gateways
- Automated asset allocation & wealth portfolio management
- KYC/AML verification workflows
- Google Email Verification & registration confirmation protocol
- Google Cloud Translation v2 key integration across 10 global languages
- Smartsupp Live Chat integration with live concierge support

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

## Environment Variables

Copy `.env.example` to `.env` and fill in your keys:
- `VITE_GOOGLE_TRANSLATE_API_KEY`: Your Google Cloud Translation API key.
- `VITE_SMARTSUPP_KEY`: Your Smartsupp Chat key from smartsupp.com.
